# Ankit Chauhan - AI/ML Developer Portfolio

A modern, responsive static portfolio website showcasing AI/ML development skills and projects.

## Features

- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI**: Clean, professional design with smooth animations
- **Skills Showcase**: Comprehensive display of technical and soft skills
- **Project Portfolio**: Featured projects with descriptions and tech stacks
- **Work Experience**: Timeline of professional experience
- **GitHub Pages Ready**: Optimized for static hosting

## Live Demo

Visit the live portfolio: [Portfolio](https://ankitchauhan19.github.io/Portfolio/)

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Icons**: Font Awesome 6.0
- **Fonts**: Google Fonts (Inter)
- **Animations**: CSS3 transitions and JavaScript
- **Hosting**: GitHub Pages (static hosting)

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers
